# luibibbo.github.io — Hola mundo

Estructura inicial para una página personal en GitHub Pages.

## Estructura

```text
index.html
assets/
  images/
    hola-mundo.png
```

## Uso

1. Crear o abrir el repositorio `luibibbo.github.io`.
2. Subir el contenido de esta carpeta al repositorio.
3. Activar GitHub Pages desde la rama principal si no se activa automáticamente.
4. Reemplazar los textos e imágenes por el contenido definitivo.
